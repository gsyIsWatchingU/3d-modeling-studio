# 个人 Skill 建模

上传 `.md` / `SKILL.md`，或输入自然语言，即可保存到个人 Skill 库。

- **本次使用**：在提交任务时选择，只影响这次建模。
- **每次必用**：在设置中固定，后端自动加入此用户的所有新任务，其他用户不受影响。
- 提交后保存完整快照；修改或删除 Skill 不改变已提交任务。

后端先用模型解析 Skill 和提示词，再执行面数、纹理预算、材质等参数，并将实际材质提示词传给纹理扩散模型。GPU 必须返回计划摘要回执；不能保证实现的要求列为待验收项。解析失败不会静默跳过 Skill。

自然语言示例：

> 使用 60000 面预算、2048 纹理上限、9 个材质视角；石材粗糙度至少 0.55，高光强度 0.2。灯光是否发亮需单独验收。

也可在 Skill 正文中写精确参数：

````md
```modeling
{"triangle_budget":60000,"roughness_floor":0.55}
```
````

固定 Skill 的精确参数优先；多个固定 Skill 参数冲突时任务报错。每份 Skill 最多 6000 字，合并后最多 12000 字。当前第一张图片参与生成，其余图片仅保留为辅助参考。

解析服务可通过 `SKILL_PLANNER_URL`、`SKILL_PLANNER_MODEL` 配置，默认使用服务器本机 Qwen 服务。上传内容仅作为数据解析，不执行其中的命令、脚本或文件操作。
