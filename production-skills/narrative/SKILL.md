# 剧本与分镜

输入：已批准的世界观、人物、玩法、场景 ID；缺失时先列假设，不发明正史。

- 每场写明：玩家目标 → 可见线索 → 行动或选择 → 世界状态变化 → 结果与下一场条件。关键故事变化必须能落到玩法。
- 人物建立欲望、矛盾、关系、措辞与禁说内容；避免人物互相讲解早已知道的信息。
- 必需信息在主路可理解，背景细节可选；用物件、痕迹、空间与声音交代因果。
- 分支先画节点关系，再写正文；注明条件、变量写入、汇合点与不可逆后果，检查不可达节点和软锁。
- 分镜注明镜头位置、时长估计、主体动作、交互窗口、关联资产与声音事件；不以长过场代替用户要求的游玩。

交付：场次表、剧情正文或对白节点、分镜表、资产与声音事件清单、连续性检查。
验收：删掉可选解释后仍懂当前目标；伏笔有对应结果；每个分支有合法出口。未试玩不声称叙事已被玩家理解。
