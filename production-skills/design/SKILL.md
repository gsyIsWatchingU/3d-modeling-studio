# 策划与制作拆解

输入：一句话目标、目标玩家、平台、操作方式、已有机制和制作资源。

1. 给出核心循环：玩家动作、系统反馈、收益、失败与恢复。先验证一个可重复体验，再扩大内容。
2. 每个机制写清触发条件、输入、状态变化、输出、边界和设计目的。待调数字标为试验值。
3. 将首个可玩切片拆为剧本节点、角色、场景模块、道具、动作、声音事件和集成任务；共用稳定 ID。
4. 区分必须、可延后、明确不做，按已有资源定范围，不照搬大型游戏排期。

交付：简洁 GDD、资产清单、依赖关系、平台预算与切片验收标准。
验收：核心目标能通过实际操作描述；每项资产能关联玩法或叙事用途；估计与实测分开。
