# 通用建模

- 保留参考图主体轮廓、比例和结构；不能从单张图确定的背面要标为推断。第一张参考图才参与当前生成。
- 优先把面数用于外轮廓和实际弯曲区域，平面减少冗余；按选择的移动端或桌面档位控制预算，不凭空提高到超出后端上限。
- 确认单位、尺寸、朝向和用途，再指定枢轴；导出时检查缩放、法线、穿插、浮片和不可见面。不能未经检查断言模型已封闭或已重拓扑。
- UV 密度以游戏镜头距离为准；接缝避开主视面，留出与纹理分辨率和 mip 相符的边距。
- PBR 明确材质、粗糙度、金属度、颜色空间和法线方向；不要把灯光阴影烘进基础色；材质纹理不得遮掩主体结构错误。
- 导出自包含 GLB，检查纹理引用、文件大小与哈希；模型应在引擎与目标设备复核。LOD、碰撞和拓扑当前不保证自动生成，列入交接与验收。

交付：模型、尺寸与枢轴说明、材质/贴图清单、预算实测值、缺陷与未验证项。
验收：游戏视角下主体可辨认、接地可信、材质符合要求；逐项用图像和检查结果证明。
