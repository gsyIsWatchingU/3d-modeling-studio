# 集成与技术美术

- 先读取实际引擎、版本、渲染路径和平台限制；复用项目架构与命名，不盲目引入新框架。
- 工厂 browser-exploration-v1 仅支持俯视移动、碰撞、收集、危险物、NPC 对话和多关卡，可交付离线 HTML/JS 工程；不承诺任意玩法、联网或自动装配 3D 资产。
- 逐项核对缩放、坐标系、材质贴图、骨架、动作、碰撞、导航、镜头、输入与资源引用。
- 状态机同时驱动动画、碰撞、交互反馈和声音事件，避免画面变化但碰撞/声音仍停留旧状态。
- UI 明确目标、反馈、暂停、失败恢复与操作可达性；交互不只依赖颜色、听觉或精确时机。
- 特效为动作与状态服务，检查遮挡、透明过绘、闪烁、亮度和低性能档位；LOD 数量按场景与设备实测确定。
- 在最低目标设备采集帧耗时、内存、纹理/三角面、加载和音频并发预算。源文件导出成功不等于运行时可用。

交付：资产映射表、引擎场景/预制件、输入与状态绑定、性能记录、未接通能力清单。
验收：真实启动、游玩、暂停/恢复、失败重试和发布包离线/在线边界；自动化不得代替实际运行。
