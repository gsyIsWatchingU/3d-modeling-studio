# 道具

- 明确装饰、可拾取、可破坏或机关用途，以及实际尺寸、材质、摆放/握持方式。
- 沿用通用建模规范；优先保结构和轮廓，再做污渍、磨损和微细节。
- 把门轴、把手、抽屉等运动件列成独立部件要求；单图生成未能分件时如实标为待后处理。
- 枢轴匹配放置、旋转或握持用途；明确碰撞范围、交互点和声音事件。

交付：模型、尺寸与枢轴、交互部件列表、材质与碰撞需求。
验收：比例、接地、连接关系、游戏视角辨识和交互运动，不把静态外观合格当成可交互。

参考：skills-gamedev/blender-modeling、tech-art（MIT）。
