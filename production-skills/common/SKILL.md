# 制作通则

- 先确认目标平台、玩家视角、玩法、风格与已确定的世界观。未提供的内容标为假设；新故事和设定标为提案，不自动改写正史。
- 各阶段用同一组场景、角色、道具和声音事件 ID 交接；注明输入版本、依赖、输出与待验收项。
- 生产规范不是生成能力。区分设计稿、可执行参数、实际生成文件和待接入服务；不把提示词当成音频，不把静态角色当成绑定动画，不把场景模型当成可玩关卡。
- 使用当前项目已有生产后端；涉及《川流不息》时叠加其专属创作规范，资产只走用户 GPU 服务器流水线，必须人工 approved 后才能进入游戏。
- 正式资产交付需保留来源许可、参考图、提示词、Skill 版本和哈希、生成任务 ID。未知来源资产不得标为可商用。
- 审查逐项给出通过、需修改或未验证，并记录证据。未看图、未试听、未导入或未试玩的项目保留未验证；生成成功不代表质量通过。
- 平台预算以项目目标和现有质量档位为准；不要照搬上游示例的面数、固定 60 帧、LOD 数量或中间件要求。

本文为本平台自有整合规范；各阶段的外部参考与许可证见 sources.lock.json 和 vendor。
