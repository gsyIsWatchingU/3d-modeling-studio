# 骨骼与动画

- 输入必须包含模型、目标引擎骨架约定、必要动作和帧率预算；不为所有游戏强行统一骨名或 60 帧。
- 明确根骨、朝向、变形骨与控制骨、缩放和骨骼上限；权重归一化，影响骨数量按目标平台约定。
- 先检查肘膝、肩胯等关键关节，再批量产动作；检查衣物和握持道具穿插。
- 每段动作注明名称、持续时间、循环、root motion 或原地模式、开始/结束条件、中断窗口和事件标记。
- 步态速度匹配角色位移，脚底接触可信；循环衔接检查姿势与速度，不只比较首尾截图。
- 烘焙引擎不支持的约束，导出后重新导入检查。当前平台无绑定/动画执行入口时交付动作规格并标待接入，不伪造动画文件。

交付：骨架约定、动作与状态表、事件表、实际动画文件（若已执行）、导入/变形验证证据。

参考：skills-gamedev/blender-animation（MIT）。
