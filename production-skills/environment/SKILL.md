# 场景与关卡

输入：玩法、角色尺寸、移动能力、镜头、场景叙事目的；沿用通用建模规范。

- 先做布局与尺度验证：入口、目标、主路线、交互点、危险、退出/恢复路线。路线长度与跳跃距离来自实际角色能力。
- 将完整关卡拆成可复用场景模块和独立交互件；门、机关、可移动物不要与背景融成单一不可操作网格。
- 固定模块网格、接缝、枢轴和朝向；给碰撞体、遮挡、导航、加载分区留出集成说明。
- 用轮廓、灯光、颜色和地标引导路线；装饰密度不盖住交互信号，重要物件不只依靠颜色辨识。
- 环境痕迹符合剧本历史；节奏有观察、学习、变化、恢复，不强行加入战斗或迷宫。

交付：布局节点表、尺寸/模块清单、场景资产、碰撞与镜头说明、声音区域清单。
验收：先验证灰盒通行、镜头与交互，再做装饰。GLB 只是场景资产，不能据此宣称关卡可玩。
