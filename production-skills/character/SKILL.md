# 角色

输入：人物设定、玩法职能、体型比例、服装、镜头距离、预期动作；沿用通用建模规范。

- 先锁定轮廓、身体比例、服装分区、关键辨识物，再添加细节；不要靠高频纹理弥补剪影不清。
- 需要绑定时明确 A/T 姿态、肢体间隙、手指与衣物分离；关节与衣物留变形空间，不擅自声称生成器已经实现。
- 道具握持点、脚底高度、身体尺寸、碰撞体尺寸和镜头构图保持一致。
- 参考图没有明确要求时不增加肢体、配饰、文字和图案；多视图造型保持同一身份。

交付：角色规格、静态模型、材质清单、绑定需求、动作清单。
验收：正侧背与游戏镜头剪影、五官/手脚、衣物穿插；绑定和动作需另行实际验证。

参考：skills-gamedev/blender-modeling、blender-animation（MIT）。
